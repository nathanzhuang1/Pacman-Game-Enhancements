# Pacman Game Enhancements
Created on Ecilipse using Java on Sunday Dec 15, 2024. Uploaded onto Github Saturday Sep 12, 2026. Open in Eclipse or IntelliJ to run PacManGame.java

## Description: 
This project is to create a functional Pac-Man game. The objective of the game is to complete all levels without losing all 3 lives in each one. This was a solo school project, with occasional guidance from classmates and family when troubleshooting specific features like audio playback and file-based score storage.

## Built With:
- Java
- Java Swing/AWT (GUI)
- Java Sound API (audio playback)

## Features:
- Title screen
- Score in game
- Lives
- Gate to forbid Pac-Man from entering house
- An 'invisible elevator' for ghosts to exit their house
- Speed-ups and cherries for score enhancements
- Sound of game theme played, sound played when pellets are eaten, and sound played when Pac-Man dies
- High score with name displayed to the reader after the game is completed.
- Leaderboard displaying the participants and their achievements

## Major Skills:
- Arraylists
- Comparator
- Hashmaps
- While/for-loops
- Try and catch to read/write a file 
- GetAudioInputStream to read clips
- Creating panels and frames.
