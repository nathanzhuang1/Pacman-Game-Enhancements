# Pacman Game Enhancements
Created Sunday Dec 15, 2024. Uploaded onto Github Saturday Sep 12, 2026. Open in Eclipse or IntelliJ and run PacManGame.java

## Description: 
This project is to create a functional Pac-Man game. The objective of the game is to complete all levels without losing all 3 lives in each one.

## Built With:
- Java
- Java Swing/AWT (GUI)
- Java Sound API (audio playback)

## Features:
- Title screen
- Basic.java -> Score, lives, adding a gate to forbid Pac-Man from entering house, creating an 'elevator' for ghosts to exit their house
- Speed-ups and cherries for score enhancements
- Sound of game theme played, sound played when pellets are eaten, and sound played when Pac-Man dies
- High score with name displayed to the reader after the game is completed.
- Leaderboard displaying the participants and their achievements
